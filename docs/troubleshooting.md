# Troubleshooting & Error Codes

| Code | Cause | Fix |
|---|---|---|
| `INVALID_LICENSE` | Key doesn't exist or is mistyped | Verify key format |
| `LICENSE_EXPIRED` | Expiry date elapsed | Extend expiry in admin console |
| `DEVICE_LIMIT_REACHED` | Maximum PC slots active | Reset device slot in admin console |
| `DEVICE_REVOKED` | PC slot unlinked | Re-activate or issue new key |
| `OFFLINE_NOT_ALLOWED` | Grace period expired | Connect to Internet to revalidate |
